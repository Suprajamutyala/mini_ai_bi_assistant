# AI Business Intelligence Assistant

## About the Project
The AI Business Intelligence Assistant is a web application that analyzes sales data and answers business questions in simple language. It helps users understand sales performance through charts, summaries, and key metrics.

## Features
- Sales revenue analysis
- Best-performing product identification
- Monthly sales trend visualization
- Region-wise sales comparison
- Revenue comparison between months
- Interactive dashboard with charts
- Natural-language business questions

## Technologies Used
- Python
- Flask
- SQL / SQLite
- HTML, CSS, JavaScript
- Chart.js
- Pandas

## Dataset
The project uses a sales dataset containing transaction dates, products, categories, regions, quantities, prices, discounts, and order status.

## How to Run Locally
1. Install Python.
2. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open `http://127.0.0.1:5000` in your browser.

## Purpose
This project demonstrates how data analysis, business intelligence, and AI-assisted question answering can help users make data-driven decisions.
